🎨 2. Vì sao pill có tab bị chìm (A)

Rule gốc đã muốn pill có tab chữ trắng + viền màu. Nhưng khối override .vbg-report dùng !important ép lại chữ xám phụ và viền trong suốt.

Fix A = sửa đúng 2 dòng trong khối override đó.

!important đè2 dòng
📄 extension/style.css
+2 -2 CSS
/* dòng 1204: rule gốc, CHẾT vì bị đè */
.perspective-tag-pill.is-active { color: var(--vbg-text-primary); }
/* dòng 1268: viền màu tag, CHẾT vì bị đè */
.is-active.has-color { border-color: color-mix(in srgb, var(--pill-color) 35%, transparent); }
/* dòng 3553: override .vbg-report thắng nhờ !important */
.vbg-report ... .is-active {
background: transparent !important;
- border: 1px solid transparent !important;
- color: var(--vbg-text-secondary) !important;
+ border: 1px solid color-mix(in srgb, var(--pill-color, transparent) 35%, transparent) !important;# A
+ color: var(--vbg-text-primary) !important;# A
}
TẦNG 2/4 • FYI

🐛 2b. Bonus bug: token không tồn tại

--vbg-text-tertiary được dùng 10 lần trong style.css nhưng đéo được định nghĩa ở đâu cả. Tag rỗng vì thế kế thừa chữ trắng rồi mờ 55%, ra màu xám gần y hệt pill có tab.

Chưa đụng vào trong combo, để m quyết.

FYI10 chỗ dùng
📄 extension/style.css (FYI)
CSS
.vbg-report ... .is-empty {
color: var(--vbg-text-tertiary) !important;# token đéo tồn tại
opacity: 0.55 !important;
}
/* var() trỏ vào token không định nghĩa → giá trị "unset" → màu kế thừa từ cha (trắng) */
/* nên tag rỗng = trắng × 0.55 ≈ xám #828282, sát rạt pill có tab (#a1a1a1) */

- item.count = 0 → pill is-empty + pill-count "0"
+ item.count = 0 → pill is-empty (đéo có count)# C
