📁 1. Cấu Trúc Tập Tin Chạm Đến

Hệ thống Recent Tabs mở rộng từ 1 tab lên 3-5 tabs chỉ cần can thiệp cục bộ vào 3 file chính trong extension:

UI Shelf MRU Logic Geist CSS
📁 extension/
STRUCTURE
├── 📄 extension/index.html# Nơi đặt container #quickReturnBar (Top Shelf)
├── 📄 extension/app.js# Logic getRecentTabs(limit: 5) + renderQuickReturnBar()
├── 📄 extension/style.css# CSS Opacity Decay variables (.decay-rank-1..5)
└── 📄 test/perspectives.test.ts# Test suite bảo đảm không regression
TẦNG 2/4 • COMPONENT & STATE

🧩 2. Cấu Trúc Data & Hàm Render

Hàm getRecentTabs() đã được thiết kế sẵn tham số limit: 5, chỉ cần cắm vào renderer Top Shelf:

Pure Data Fitts's Law
📄 extension/app.js
JS
function renderQuickReturnBar(tabs) {
+ const recentTabs = getRecentTabs(tabs, { limit: 5 });# Lấy tối đa 5 tab MRU
if (!recentTabs.length) return;
+ const chipsHtml = recentTabs.map((tab, idx) => {
+ const kbd = idx === 0 ? 'Esc' : `${idx + 1}`;# Phím tắt Esc hoặc số
+ return `<button class="recent-shelf-chip decay-rank-${idx + 1}" data-tab-id="${tab.id}">
+ <kbd>${kbd}</kbd> <span>${tab.title}</span></button>`;
+ }).join('');
}

onUserOpensNewTab()
